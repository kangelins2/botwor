Телеграм бот на aiogram с web app промо страницей и использованием fastapi
Цель: Создание лендинг-маркетинг странички

Задача: Создать бота с мини-апп со ссылками на другие платформы + форма по сбору email.

Использование библиотек в проекте:
Библиотеки, такие как asyncio, anyio, uvicorn, sqlalchemy.ext.asyncio, aiogram, и fastapi — играют ключевую роль в создании асинхронных приложений, позволяя обрабатывать множество операций одновременно.
pydantic обеспечивает простую валидацию данных, а pandas используется для работы с данными и их преобразованиями (в данном случае — сохранение email в CSV).
Стандартные библиотеки os и typing представляют вспомогательные инструменты для работы с окружением и типами данных.
Вместе эти библиотеки создают мощный стек для разработки асинхронного веб-приложения с поддержкой работы с базами данных и интеграции с Telegram.


Архитектура кода:
1. Структура приложения
- **FastAPI**: Используется для создания веб-приложения и обработки HTTP-запросов. В данном случае определены маршруты для получения и сохранения адресов электронной почты.
**Aiogram Dispatcher**: Отвечает за маршрутизацию сообщений Telegram и обработку команд от пользователей бота.
2. Модель данных
- **SQLAlchemy**: ORM (Object-Relational Mapping) библиотека, используемая для взаимодействия с базой данных. Здесь определена модель `Email`, которая позволяет хранить электронные адреса.
- **Pydantic**: Используется для валидации и сериализации входящих данных в API (например, `EmailRequest`), что позволяет упростить работу с данными, приходящими от клиента

3. Асинхронное выполнение**
- **asyncio** и **AnyIO**: Являются основными библиотеками для работы с асинхронным кодом, позволяя эффективно обрабатывать множество операций одновременно, включая обработку HTTP-запросов и бота Telegram.
**task groups** (в Anio) позволяют организовать выполнение нескольких асинхронных задач параллельно, в данном случае — сервер FastAPI и бот Telegram.
4. Конфигурация и окружение**
**dotenv**: Позволяет загружать переменные окружения из файла `.env`, что упрощает работу с конфигурациями и секретами (например, токены доступа к API и URL базы данных).
5. Обработка маршрутов
- **Маршруты API**: В FastAPI определены два маршрута: один для получения "Hello World", другой для обработки сохранения электронной почты. Первый — GET, второй — POST. 
- **Команды Telegram**: Используются фильтры Aiogram для обработки команд, например, `CommandStart` для приветственного сообщения и `Command` для скачивания списка почтовых адресов.
6. Сохранение и получение данных
Асинхронные функции, например, `save_email` и `download_price`, отвечающие за сохранение новых адресов электронной почты в базе данных и скачивание всех адресов в виде CSV-файла, соответственно
